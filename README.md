# Lavagna CLI

Binaries of `lavagna`, the command that works on Lavagna projects from a terminal.
This repository holds only the releases; the source is not public.

## Install

- macOS: `brew install --cask lavagna-ai/tap/lavagna`
- Windows: `scoop bucket add lavagna https://github.com/lavagna-ai/scoop-bucket`,
  then `scoop install lavagna`
- Linux: the `.deb`, `.rpm` or `.apk` of the [latest release](https://github.com/lavagna-ai/lavagna-cli/releases/latest)
- Any system: the archive for your system from the same release; `checksums.txt`
  lists the SHA-256 of every file.

## Use

```bash
lavagna login
lavagna --help
```
